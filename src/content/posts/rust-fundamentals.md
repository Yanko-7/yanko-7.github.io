## 变量可变性

rust中变量默认是不可变的，要想可变需要添加mut关键字`let mut x = 5；`
注意的是，let 的寓意应该被认为是绑定，即将一片内存空间绑定于变量。

### 一些声明方式：

- `let a : i32 = 1;`仅在初始化时候可以用`: i32`赋值声明
- `let a = 1_f64;`同上
- 常量的声明 `const MAXN: u32 = 100000;`
- Rust支持作用域内变量遮蔽
- **使用下划线开头可以让编译器对未使用的变量不报错**

## 字面量和运算符

学到这里感觉Rust真的很高级
整数 `1`、浮点数 `1.2`、字符 `'a'`、字符串 `"abc"`、布尔值 `true` 和单元类型 `()` 都可以直接作为字面量
甚至可以十六进制(0x)，八进制(0o)，二进制表达(0b)。
同时支持在数值字面量中加入下划线改善可读性。比如：`1_000` 等同于 `1000`，`0.000_001` 等同于 `0.000001`。

一些例子
字面量可以用`0x80_u32`表示，也可以`0x80u32`

```rust
let a = 0x80_u32; //十六进制转u32.
let a = 0b0011u32 ^ 0b0101; //支持与c一样的位运算符 此处二进制转u32后与另一个二进制数进行异或
// 使用下划线改善数字的可读性！
println!("One million is written as {}", 1_000_000u32);
```

> [!NOTE] NOTE
>
> - **Rust 拥有相当多的数值类型**. 因此你需要熟悉这些类型所占用的字节数，这样就知道该类型允许的大小范围以及你选择的类型是否能表达负数
> - **类型转换必须是显式的**. Rust 永远也不会偷偷把你的 16bit 整数转换成 32bit 整数
> - **Rust 的数值上可以使用方法**. 例如你可以用以下方法来将 `13.14` 取整：`13.14_f32.round()`，在这里我们使用了类型后缀，因为编译器需要知道 `13.14` 的具体类型

## 字符、布尔、单元类型

### 字符类型（char）

比较怪异的一点是

```rust
let g = '国'; 
let heart_eyed_cat = '😻';
```

Rust中的字符类型是并不是ASCII编码，而是Unicode。所以Rust的char占4个字节。

### 布尔类型（bool）

`let f: bool = false;`需要注意的是bool占1个字节

### 单元类型（()）

以前没有见过的一种类型。其唯一值就是().
类似于C的void，但在Rust中，不能说其是没有返回值的函数。
如`fn main()`其返回值就是()，在Rust中，没有返回值的函数被单独定义成了“发散函数”，即无法收敛的函数。
()也类似于Golang的struct{}，可以作为一个值来占位，但是完全不占用内存。

## 一些注意点

i8 i16 i32
比较独特的类型为size 分为isize 和usize。
size的意思为视架构而定的整数（即取决于CPU处理位数）

- `let i = 1` 默认为i32
- `let i = 1.1`默认为f64

> [!NOTE] NOTE
>
> Debug模式下进行编译时，Rust会检查整形溢出报错。
> Release模式则不会检查溢出。
> Rust强类型规范，甚至u32和i32的比较或者赋值都是不被允许的，需要显式说明

浮点的f32和f64在现代计算机上性能差不多，最好用f64

## 序列

类似于python的range

- `1..5`生成1~4 左闭右开
- `1..=5`生成1~5，包括右端点

同时也支持字符类型`'a'..'z'`
可以用于控制流中

```rust
for i in 'a'..= 'z'{
	println!("{}",i);
}
```

## As的使用（类型转换）

上面说到rust对类型非常严格，需要显式转换。
如

```rust
fn main() {
  let a: i32 = 10;
  let b: u16 = 100;

  if a < b { // -> 变为 a < (b as i32)
    println!("Ten is less than one hundred.");
  }
}
```

`(变量 as 需要转换的类型)`

还可以通过`i32::MAX`访问基本类型的最大值等,甚至还封装了函数`i32::abs()`
