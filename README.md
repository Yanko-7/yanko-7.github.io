# Yanko — research & engineering notes

Yongkang Qi's personal site, built on [AstroPaper](https://github.com/satnaing/astro-paper). Geometry, generative CAD, inference systems, and a working notebook in Chinese.

## Local development

Use **Node 24 LTS** and npm.

```sh
npm ci
npm run dev
```

Open `http://localhost:4321/`. For the complete site, including search:

```sh
npm run build
npm run preview
```

Search is generated by Pagefind during the production build. Preview at `http://localhost:4321/` to test it.

## Editing

- `astro-paper.config.ts`: site identity, links, pagination, feature flags.
- `src/pages/index.astro`: home page.
- `src/content/pages/about.md`: profile, research, experience, education.
- `src/content/posts/*.md`: articles. Set `draft: true` to keep a post out of routes, search, RSS, and archives.
- `src/styles/theme.css`: light/dark colors and font stack.
- `public/assets/pdf/cv.pdf`: original CV, retained at its existing URL.

Example article metadata:

```yaml
---
title: A useful title
pubDatetime: 2026-09-20T12:00:00+08:00
description: A short, concrete description.
tags: [systems]
lang: zh-CN
featured: false
draft: false
---
```

Markdown supports fenced code and KaTeX math. File names become article URLs; use stable descriptive slugs. The UI and profile are in English; original Chinese article bodies retain their language. System fonts keep the site independent of remote font services.

## Validation

```sh
npm run format:check
npm run lint
npm run build
npm test
npx playwright install chromium
npm run test:browser
```

Browser checks cover mobile navigation, dark mode, production search, article math, and horizontal overflow.

## GitHub Pages

The workflow builds on pull requests and deploys pushes to `main` or `master`. In GitHub **Settings → Pages → Build and deployment**, select **GitHub Actions** if the repository still uses a branch source. The canonical URL is `https://yanko-7.github.io/`, with no project subpath.
